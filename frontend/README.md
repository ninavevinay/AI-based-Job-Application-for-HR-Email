# 🎨 Frontend - AI Job Application Studio

This is the frontend client for **AI Job Application Studio**, built using **React 19**, **Vite**, and **Tailwind CSS v4**.

For complete project documentation, backend setup, database details, and API documentation, please refer to the [Root README.md](../README.md).

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env`:
   ```env
   VITE_APP_BASE_URL=http://127.0.0.1:8000/
   ```

3. Start development server:
   ```bash
   npm run dev
   ```
